# Cntrl Alt Del

**Challenge 1 - Equipe Ctrl Alt Del - Sistemas de Machine Learning 2026/02**

---

## Sobre o Projeto

O projeto visa ajudar Jovens que utilizam redes sociais, sendo mais específico, o Instagram, a identificar se, notícias durante o período eleitoral são veridicas, com um sistema que consegue coletar textos por meios de imagens e fazer a validação se é ou não algo desinformativo.

## Dados

O sistema utiliza dados do **Tribunal Superior Eleitoral (TSE)**, onde possuí dados abertos de todos os candidatos que estão se elegendo em todos os estados do Brasil.
